# GoodFlow：公益图文转视频

将公益项目文字与授权素材整理成脚本、分镜、配音、字幕及视频的 AI 工作流。交付形态为 public-good-video-director Skill，需要在支持 Skill 的 AI 工具中安装和运行。

[下载 Skill 安装包](https://github.com/w88856678-rgb/goodflow/releases/download/v2026.09.20/goodflow-skill.zip)

## 使用方式

解压安装包，将 public-good-video-director 文件夹放入支持 Skill 的 AI 工具的技能目录。提供公益项目介绍、已获授权的图片以及视频时长要求，再让工具使用该 Skill 制作视频。按提示配置本地渲染依赖和自己使用的模型服务，密钥只保存在本地。

此安装包不包含模型额度，不是免安装的在线视频生成服务。脚本确认、素材授权、配音和成片检查流程见 SKILL.md。最终质量取决于输入素材和所配置的服务。
