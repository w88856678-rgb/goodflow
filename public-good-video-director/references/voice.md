# Voice sourcing and naturalness

## Provider-neutral default

Choose the best callable speech capability according to `provider-routing.md`. Target a warm, restrained, conversational Mandarin documentary delivery regardless of provider. Evaluate the final Chinese script with the same voice, not only a provider demo.

When Alibaba Bailian is selected as fallback, use `cosyvoice-v3.5-plus` with `warm-documentary` as the starting profile.

For a no-API speech path, compare Edge TTS and Kokoro Chinese using the approved script. Edge is the default lightweight audition because it installs quickly and exposes timing metadata; Kokoro is the privacy/offline choice after its model is downloaded. Judge breath, phrase endings, number reading, and the emotional turn—not only timbre. Run `align_narration.py` after selecting the full narration.

If the user cannot choose a voice from description alone, generate three Edge candidates with the same approved excerpt and identical rate/pitch settings:

- A `zh-CN-XiaoyiNeural`: clear, friendly, useful for warm news and project updates.
- B `zh-CN-YunxiNeural`: younger conversational male delivery.
- C `zh-CN-YunyangNeural`: steadier information-led male delivery.

These are comparison defaults, not universal winners. Present the three playable files, describe their delivery briefly, and wait for A/B/C selection before synthesizing the full film. Run `scripts/audition_voice_trio.py PROJECT --rate=+6% --pitch=+1Hz`; use a user-requested pace such as `+10%` consistently across all candidates.

## Pronunciation aliases

Fix awkward brand names, initials, polyphones, and foreign names without changing approved copy or captions. Store speech-only replacements in `workflow/tts-pronunciations.json`:

```json
{
  "replacements": {
    "QQ": "Q Q "
  }
}
```

Create or update an alias with `scripts/set_pronunciation.py PROJECT --written QQ --spoken "Q Q "`. Auditions and full Edge/Kokoro generation apply the mapping; the approved narration remains the alignment source. Always regenerate speech, provider word boundaries, timestamps, and timeline after changing an alias.

The skill includes four same-script samples in `assets/voice-auditions/`. Play them before creating a new account-specific voice. The included audio contains no API key or account-bound voice ID and must not be used as cloning input.

The bundled profiles borrow only general listening attributes from these MiniMax system-voice categories:

- `Chinese (Mandarin)_Warm_Bestie`
- `Chinese (Mandarin)_Gentle_Senior`
- `Chinese (Mandarin)_Soft_Girl`
- `Chinese (Mandarin)_Sincere_Adult`

Do not feed MiniMax output into Bailian as cloning audio. A system voice can be auditioned as an aesthetic reference, but its timbre is not a reusable training asset.

## Safe source hierarchy

1. An original voice-design prompt on the selected provider: safest default.
2. User’s own voice or an explicitly contracted narrator: best for a stable brand voice.
3. A recording with written consent covering synthesis, commercial use, duration, territory, and revocation: acceptable for cloning.
4. Open speech corpora: useful for research, not automatically suitable for adopting one identifiable speaker as a public brand voice.
5. Random GitHub audio, podcasts, social video, celebrity speech, or another provider’s system voice: do not clone.

AISHELL-3 is an Apache-2.0, emotion-neutral, multi-speaker Mandarin TTS corpus. Its code/data license does not by itself document the individual consent and publicity-right scope needed to turn a particular speaker into a commercial synthetic brand voice. Treat it as research material unless additional authorization is verified.

## Naturalness checklist

- Synthesize one semantic beat at a time.
- Put emotional direction on the beat, not on the whole film.
- Use punctuation that reflects spoken phrasing.
- Replace written-language transitions with spoken Chinese.
- Remove scripted interjections such as “哇” unless a real speaker would say them.
- Keep most delivery neutral; deepen emotion only on the human detail.
- Allow 120–220 ms between beats; do not erase every breath.
- Prefer rewriting over aggressive speed-up.
- Read numbers, dates, and place names aloud during review.
- Include any configured pronunciation alias in the audition excerpt when possible.
- Audition the final script, not a generic demo sentence.

## Authorized cloning intake

Before adding a cloned voice, obtain:

- speaker identity and consent record;
- allowed projects and channels;
- commercial-use permission;
- expiration and revocation rules;
- a clean 20–60 second dry recording without music or reverb;
- confirmation that the recording is not generated by another TTS provider.

Store consent metadata next to the voice profile, but keep personal documents and raw recordings out of Git and final deliverables.
